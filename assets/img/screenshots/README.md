# Скриншоты проектов

Сюда складываются скриншоты для сайта. Одна папка — один проект.
Имя папки = `id` проекта из `data/projects.json`.

```
assets/img/screenshots/
├── survmine/          ← SurvMine
├── survmine3d/        ← SurvMine 3D
├── tankgame/          ← TankGame
├── quest/             ← Демоны молодости
├── trainsimulator/    ← VR-тренажёр ЕРМАК
└── …                  ← ещё 28 папок
```

## Как добавить скриншоты

1. Открой папку нужного проекта.
2. Положи туда картинки: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif`.
3. Запусти генератор (или просто `serve.bat` — он сделает это сам):

```powershell
.\screenshots.bat
# либо
node tools/screenshots.js
```

4. Обнови страницу. Первый скриншот станет обложкой карточки,
   остальные появятся в галерее внутри модального окна (с лайтбоксом).

## Как выбрать обложку

- Назови файл так, чтобы он начинался с `cover` или `обложка` — например
  `cover.png` или `обложка-minecraft.jpg`. Он станет обложкой.
- Если такого файла нет, обложкой станет первый после естественной
  сортировки (`1.png`, `2.png`, …, `10.png`).

## Рекомендации

- Обложка: соотношение **16:9**, ширина 1280–1920 px.
- Галерея: тот же 16:9, ширина 1600–2560 px.
- Формат: `.webp` или `.jpg` — они легче `.png` при том же качестве.
- Не кладите сюда чужие арты из Asset Store: только собственные кадры
  игры/приложения (геймплей, сцены, UI).
- Хороший набор для VR: 1 обложка + 3–5 кадров (меню, геймплей, локация).
- Файлы `.gitkeep` можно не удалять — они просто держат пустые папки в git.

## Что происходит под капотом

`tools/screenshots.js` сканирует все папки и пишет `data/screenshots.json`:

```json
{
  "projects": {
    "survmine": {
      "cover": "assets/img/screenshots/survmine/cover.png",
      "images": ["assets/img/screenshots/survmine/cover.png", "assets/img/screenshots/survmine/2.png"]
    }
  }
}
```

Сайт читает этот файл при загрузке. Если папка пуста — проект просто
показывает прежнюю градиентную обложку, ничего не ломается.
